# Доббль — автоматизация слов 4-го класса

Автономная игра: 8 раундов, 14 предметов, две карточки по 5 картинок. Нажмите на общий предмет в любом круге и назовите его вслух. Переход через 1,5 секунды. Ошибки не ограничивают попытки. Озвучивания слов и статистики нет.

## Запуск
Откройте `index.html` или разместите содержимое папки на статическом хостинге. Сборка и внешние сервисы не нужны. Все PNG находятся в `assets/`. Звуки синтезируются браузером после взаимодействия.

## GitHub Pages и Genially
В Settings → Pages выберите Deploy from a branch → main → / (root).
Ожидаемый адрес после публикации: https://propodgotovkaa-creator.github.io/dabble_4_slogova/

В Genially добавьте внешний контент:

```html
<iframe src="https://propodgotovkaa-creator.github.io/dabble_4_slogova/" width="960" height="540" style="border:0; width:100%; aspect-ratio:16/9;" title="Доббль — найди одинаковые картинки" allow="autoplay" allowfullscreen></iframe>
```

Для телефона рекомендуется открыть игру на весь экран. Круги остаются рядом. Проверять iframe следует в опубликованной презентации Genially.

## Проверка генерации
`node test-rounds.cjs`

В каждом раунде проверяются размеры групп и единственное пересечение. Общие предметы не повторяются в пределах игры. Предметы, ещё не показанные, получают приоритет при выборе отвлекающих картинок, что гарантирует показ всех 14 слов уже за первые два раунда.
